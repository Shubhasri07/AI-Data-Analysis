# AI-Data-Analysis
## Problem Statement
This project helps users upload datasets and perform data analysis using AI.

## Features
- CSV file upload
- Excel file upload
- JSON file upload
- Automatic column detection
- Missing value handling
- Average calculation
- Highest and lowest value analysis
- Data grouping and charts
- AI-based questions and answers
- Error handling
